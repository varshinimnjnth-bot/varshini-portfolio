# Varshini's Portfolio

Responsive portfolio built with HTML, CSS and a small amount of JavaScript.

## Before publishing
- Replace `YOUR_EMAIL_HERE` with your professional email.
- Replace `YOUR-LINKEDIN-USERNAME` with your LinkedIn profile username.
- Verify education and achievement details.
- Update the Smart Solar project card with your actual role, features and technologies.

Keep `index.html`, `style.css` and `script.js` in the repository root. Publish from `main` / `/(root)` using GitHub Pages.
